# DaysUntil Mobile

"Days Until" is an ADHD-friendly mobile application dedicated to tracking time remaining until highly anticipated events. Unlike traditional planners that induce task anxiety, this application externalizes anticipation by delivering a daily, tactile micro-reward for acknowledging the passage of time.

## Functional Requirements

- Event Creation: Users input an event string and select a target date via a native mobile picker.
- Manual Tracking: Users tap the current calendar date to visually mark it as completed.
- Transient Animation: Tapping the date initiates an immediate, oversized checkmark overlay and hardware haptic vibration.
- Auto-Reconciliation: The system automatically crosses out unattended past days upon application foregrounding.
